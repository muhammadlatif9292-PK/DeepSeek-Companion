1. Getting Started

DeepSeek Companion adds a powerful sidebar panel to chat.deepseek.com. Once installed, a small toggle button appears on the right edge of the DeepSeek page.

Opening the Sidebar

Click the small ◧ grid icon on the right edge of the page to toggle the companion sidebar open and closed. You can also click the extension icon in your browser toolbar.

First Things to Try

  • Open a chat on DeepSeek that has code in the response
  • The extension will automatically detect code blocks and show a ⬇ download button next to them
  • Open the sidebar → Code Vault tab to see all detected files
  • Try 📄 PDF export from the Export Center tab

2. Code Downloader

The extension automatically scans every DeepSeek response for code blocks and adds a download button to each one.

Filename Detection

The extension uses 4 levels to detect filenames:

  1. Explicit filename in the text before the code block (e.g., "Save as App.jsx")
  2. Language tag on the code block (e.g., ```python → script.py)
  3. Content analysis — reads the code to guess the type
  4. Fallback — defaults to code_block.txt

Renaming Files

In the Code Vault tab, click on a filename to edit it before downloading.

Downloading All Code as ZIP

Click 📦 ZIP All in the Code Vault header to download all detected files as a single ZIP archive with automatic folder organization.

3. Exporting to PDF

Go to the Export Center tab → choose export scope → click 📄 PDF.

Choosing a Theme

Four themes are available: DeepBlue (default), Obsidian (dark), Scholar (academic), and Emerald. Select from the PDF Options dropdown.

Exporting a Full Conversation

Select "Entire conversation" from the scope selector to export all assistant messages in the current chat.

4. Exporting to DOCX

Click 📝 DOCX in the Export Center. The file will download as a properly formatted Word document with headings, code blocks, and tables.

Open in Microsoft Word, Google Docs, or LibreOffice.

5. Bookmarks

Hover over any DeepSeek response message — a 🔖 bookmark icon appears in the top-right corner. Click it to bookmark the message.

View all bookmarks in the 🔖 Bookmarks tab. You can assign labels, filter by label, and export all bookmarks as a PDF summary.

6. Templates

Templates let you save reusable prompts and insert them into DeepSeek's input box with one click.

Creating a Template

Go to the 📝 Templates tab → click + New → enter a name, category, and template text.

Using Variables

Use {{variable_name}} placeholders in your template. When you click "Use", a small form will appear asking for each variable.

Importing Templates

Click 📥 Import and select a .json file of templates previously exported from this extension.

7. Gemini AI Bridge

The ✨ AI Bridge tab sends any DeepSeek response to Gemini for reformatting, summarizing, translating, or other processing.

Available Modes

  • Reformat & Beautify — restructures content with headings and examples
  • Summarize — creates 3-5 bullet points
  • Expand & Elaborate — adds more detail and examples
  • Simplify — explains at beginner level
  • Extract Key Points — lists facts and action items
  • Translate — translates to your chosen language
  • Custom Prompt — your own instruction

9. FAQ

Why wasn't my filename detected?

The extension looks for filename patterns in the text before the code block. Try explicitly mentioning the filename, e.g., "Save this as App.jsx". The extension has 4 fallback levels and will always give you a downloadable file.

The extension stopped working after a DeepSeek update

DeepSeek may have changed their page structure. The extension uses resilient selectors, but major redesigns can affect detection. Try refreshing the page. If the issue persists, check for an extension update.

How do I reset everything?

Go to Settings → General → Reset All Settings. This clears all settings, bookmarks, and templates from storage.

Is my data sent anywhere?

Your data stays in your browser. The only external request is when you use the Gemini AI Bridge, which sends the selected text to Google's Gemini API using your configured key.

10. Privacy Policy

DeepSeek Companion stores the following data locally in your browser only:

  • Bookmarks (chrome.storage.local)
  • Templates (chrome.storage.local)
  • Settings and preferences (chrome.storage.sync)
  • Export history (chrome.storage.local)

No data is sent to external servers except Gemini API calls, which are made directly from your browser to Google's API using your key.

To delete all stored data: Settings → General → Reset All Settings.
