1. Getting Started

DeepSeek Companion Pro adds a sidebar to chat.deepseek.com. A small toggle button appears fixed on the right edge of the page — click it to open the sidebar.

First steps

  • Open a DeepSeek chat that contains code in the responses
  • Click 🔍 Scan in the Vault tab — the extension will scroll through the chat and extract all code files
  • Each detected code block gets a ⬇ download button injected directly into its toolbar
  • Use 📦 ZIP All to download everything as a single ZIP

2. Code Vault

The Vault is your central file list. Every code block extracted from the chat lands here.

Filename detection — 5 levels

  1. Line-1 comment (highest confidence): if you use the DSC AI Coding Prompt, DeepSeek writes the file path as the first comment in every block — e.g. // src/components/Button.tsx
  2. Preceding text: backtick-quoted filenames, bold filenames, "File:" labels in the text above the block
  3. Path context: multi-segment paths like src/api/index.ts in surrounding text
  4. Language tag: uses the language name to pick a sensible default (python → script.py)
  5. Content analysis: inspects the code itself for syntax clues as a last resort

Version resolution

When DeepSeek rewrites a file across multiple messages, only the last occurrence is kept in the Vault — that is always the most recent version. Anonymous blocks (no detected path) are deduplicated by content fingerprint.

Renaming files

Click the filename text in any card — it becomes editable inline. Press Enter or click away to save.

3. Export

The Export tab lets you export the entire chat or just the last response as PDF, DOCX, Markdown, or plain text.

  • Scope: "Last response only" or "Entire conversation" (respects Zone if active)
  • PDF Options: theme, cover page, TOC, page numbers, syntax highlighting
  • Recent exports are logged at the bottom for quick reference

4. ZIP Patcher

This is the most powerful feature. When DeepSeek has updated your project across multiple responses, your Vault has the latest versions of all files. The Patcher merges them into your existing ZIP:

  1. Scan the chat first to populate the Vault (Vault tab → 🔍 Scan)
  2. Go to the 🔧 Patcher tab
  3. Upload your existing project ZIP (drag & drop or click)
  4. Click Patch & Download ZIP

What it does

  • New files (in Vault but not in ZIP): added
  • Changed files (content differs): replaced with Vault version
  • Unchanged files: left untouched
  • Files only in ZIP: preserved exactly as-is

A full patch report shows exactly what was added, updated, and unchanged.

5. Zone Selector

The Zone lets you limit scanning and export to a specific range of messages — useful in long chats where only the last 10 messages are relevant.

Setting a zone

  • Click mode: press "Set START" then click the first message on the page, then "Set END" and click the last
  • Type mode: enter message numbers directly and press Apply
  • Presets: Last 5 / 10 / 20, First 10

Zone applies to: Vault scanning, ZIP All, and all export formats. A purple 🎯 badge appears on the Vault and Export tabs when a zone is active.

6. Dev Tools

  • Stats: total files, combined size, total lines, number of languages
  • Quick Prompts: 12 one-click prompts inserted directly into the DeepSeek input (Code Review, Write Tests, Refactor, TypeScript conversion, Dockerfile, CI/CD, etc.)
  • Clipboard: copy all code concatenated, just filenames, a file tree, or export as JSON
  • AI Coding Prompt: copies the full system prompt to paste at the start of a DeepSeek session — this is what makes file-path detection work perfectly

7. The AI Coding Prompt

For best results, paste this prompt at the very start of every coding conversation on DeepSeek. It instructs DeepSeek to always write the full file path as the first comment line in every code block, which gives the extension 100% accurate filename detection.

Find it in: Dev Tools tab → Copy Full Prompt

Example of what DeepSeek produces with the prompt active

// src/components/Button.tsx
export function Button({ label }: { label: string }) {
  return <button>{label}</button>;
}

The extension reads that first comment line and assigns exactly src/components/Button.tsx as the filename — no guessing needed.

8. FAQ

The scan found 0 files
Make sure you are on chat.deepseek.com with an actual chat open. Try clicking Scan — it scrolls through the page to trigger lazy-loaded content.
Filenames are wrong
Use the AI Coding Prompt (Dev Tools tab) at the start of your session. Without it, the extension guesses based on context — with it, detection is exact.
The ZIP Patcher shows 0 added/updated
Make sure the Vault is populated first (Scan the chat), and that the code content actually differs from what is in your existing ZIP.
A file appears multiple times in the Vault
Scan again — the version resolver keeps only the last occurrence per path. If a file has no detected path it may appear as separate anonymous blocks.
The extension doesn't detect the DeepSeek input box
Quick Prompts need the DeepSeek input to be a textarea or contenteditable element. This works on the standard chat.deepseek.com interface.
